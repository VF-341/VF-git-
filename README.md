# 健康熱量管理師 Health Calorie Manager

一個全面的健康熱量追蹤網站，幫助你記錄每日熱量攝入與消耗，並提供個人化健康建議。

A comprehensive calorie tracking website that helps you log daily calorie intake and expenditure with personalized health advice.

## 功能 Features

- **儀表板 Dashboard** — 每日熱量平衡一目了然，含七日趨勢圖表
- **熱量攝入 Calorie Intake** — 拍照/上傳食物照片，輸入重量與配料表精準計算熱量
- **熱量消耗 Calorie Burn** — 結合配速、天氣、溫度、濕度精準計算運動消耗
- **健康提醒 Health Reminders** — 飲水追蹤、久坐計時器、用餐/睡眠/運動提醒
- **個人設定 Profile** — BMR/TDEE 計算，BMI 分析，目標設定
- **多語言 Multi-language** — 繁體中文、簡體中文、English、日本語

## 技術栈 Tech Stack

- HTML / CSS / JavaScript (vanilla)
- LocalStorage for data persistence
- Open-Meteo API for weather data
- MediaDevices API for camera access
- Internationalization (I18N) with auto-detection
